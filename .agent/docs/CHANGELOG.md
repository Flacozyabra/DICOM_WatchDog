# Changelog

## [1.7.2] - 2026-08-05
- Исправлено обнаружение голосов RHVoice (`Aleksandr`, `Anna`, `Elena`) из реестра Windows (`TokenEnums`).
- Защита от сброса настроек голоса на стандартный звук WatchDog при задержках системы.
- Добавлено нечеткое сопоставление вариантов написания имён дикторов (`Alexandr` ↔ `Aleksandr`).
- Увеличен таймаут получения голосов SAPI до 8 секунд для защиты от холодного старта.

## [1.7.1] - 2026-08-03
- Исправлена ошибка `UnboundLocalError` для переменной `ps_code` при воспроизведении стандартных WAV-звуков уведомлений.

## [1.7.0] - 2026-08-03
- Добавлены раздельные независимые ползунки регулировки громкости для КТ и PACS уведомлений.
- Добавлена гибкая настройка локального порта фонового DICOM SCP сервера.
- Фоновый DICOM сервер переведен на универсальный прием C-STORE для любых AET (`DW_GAMMA`, `DE_PLANW_S` и др.).
- Реализован автоматический фолбэк на каскадный C-GET протокол при отказах C-MOVE (код 0xC000, актуально для Orthanc PACS).
- Добавлено контекстное меню при клике ПКМ в таблице PACS с действием «Отправить в CT images».
- Исправлено поведение C-ECHO (Ping) с чистой ассоциацией Verification SOP Class.
- Исправлена ошибка `NameError: name 'tr_ui' is not defined` в функции пинга.
- Оптимизирован процесс скачивания: убраны лишние циклы повторов и сбросы прогрессбара при успешном получении файлов.

## [1.5.8] - 2026-07-31
- Fixed PACS server polling bug when autoupdate switch is off.
